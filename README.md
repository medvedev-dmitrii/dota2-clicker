Небольшой помощник для мини-игры Automaton Attack в Dota 2 на Windows.

Скрипт не использует OCR и не пытается распознавать движущиеся слова. Он быстро перебирает английские буквы, поэтому мини-игра фиксирует очередную подходящую букву активного слова. Такой способ работает только пока неправильные нажатия в Automaton Attack не дают штрафа.

Что понадобится:
	    Windows 10 или Windows 11;
	    Python 3.11, 3.12 или 3.13;
			подключение к интернету для первоначальной установки двух библиотек;
			английская раскладка клавиатуры.
